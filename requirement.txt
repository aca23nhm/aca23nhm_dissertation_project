Step 5: Style / Over-Correction Evaluator
(Compare system output to original learner sentence)

Word-level Levenshtein Distance

Split both sentences into word tokens (simple whitespace split)

Compute edit distance (# insertions + deletions + substitutions)

Edit Density

edit_density = edit_distance / max(1, number_of_words_in_source)

Lexical Diversity Shift (TTR)

TTR(sentence) = unique_words / total_words

ΔTTR = abs(TTR(output) - TTR(source))

Readability Change (Flesch–Kincaid Grade Level)

Compute FK grade for source and output, then take absolute difference

ΔR = abs(FK(output) - FK(source))

Stylometric Similarity (Cosine Similarity)

Build the same feature vector per sentence, then compute cosine similarity between source and output.

Features:

Sentence length (words)
Average word length
Punctuation counts
POS-tag proportions (if applicable)

Compute:

cos_sim = cosine(vec_source, vec_output)

Step 6: Composite Over-Correction Index (OCI)

Make all components comparable to avoid domination of any single component.

Normalise each component to 0–1 using min-max normalisation computed on the whole dataset.

norm(x) = (x - min) / (max - min)

Apply weights:

OCI = α * norm(edit_distance) + β * norm(ΔTTR) + γ * norm(ΔR)

Freeze weights before running the experiment.

Example:

α = 0.5
β = 0.25
γ = 0.25

Store OCI per sentence per condition.

Paired Significance Tests
(For each comparison needed: baseline vs structured prompt)

Check if differences look approximately normal (simple normality test)

If normal → paired t-test
If not normal → Wilcoxon signed-rank test

Effect Sizes

Paired t-test → Cohen’s d (paired version)

Cohen’s d = mean(diff) / std(diff)

Wilcoxon → rank-based effect size

Example:

r = Z / sqrt(N)
